Cara menulis rincian perhitungan

Setiap pekerjaan punya baris-baris hitung bebas. Isi kolom rumus dengan angka atau rumus: 14*24,5, L2*L3, PF*0,8*TF. Desimal pakai koma, pemisah argumen pakai titik koma. L3 berarti baris ke-3 pada pekerjaan itu. Kode (misalnya PF) membuat nilai bisa dipakai di pekerjaan lain, cocok untuk data Properti. Fungsi: SUM(L4;L8), SUM(L2:L5), MAX, MIN, CEIL, ROUND(x;2), SQRT, COS(derajat), PI. Tandai baris hasil dengan pilihan "volume". Pakai "+ Judul blok" untuk Blok A, Blok B, dan seterusnya.

Google Drive

Simpan dan buka RAB langsung dari Google Drive Anda. Aplikasi hanya bisa melihat berkas yang dibuatnya sendiri.

Cara mendapatkan Client ID

1) Buka console.cloud.google.com, buat project. 2) Aktifkan Google Drive API. 3) APIs & Services → Credentials → Create OAuth client ID → Web application. 4) Pada Authorized JavaScript origins isi alamat tempat file ini dibuka (mis. https://nama.github.io atau http://localhost:8000). 5) Salin Client ID ke kolom di atas. Cukup sekali. Fitur ini tidak berfungsi bila file dibuka langsung dari folder (file://); gunakan hosting atau localhost.
